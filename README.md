# geohash-viewer

[Geohash-viewer](https://stensaethf.github.io/geohash-viewer/) is a dynamic tool for visually exploring Geohashes.

[Wikipedia](https://en.wikipedia.org/wiki/Geohash): "Geohash is a hierarchical spatial data structure which subdivides space into buckets of grid shape."

Use it at: https://stensaethf.github.io/geohash-viewer/

Created in collaboration with ChatGPT
